# react-wrapped

A year in review, played as a video, in React. The stage, scenes, charts, transitions, player, editor, scanner and
graphics behind
[Hype Stack's Wrapped](https://www.hype-stack.dev/wrapped?utm_source=react-wrapped&utm_medium=referral&utm_campaign=readme),
as packages you can take apart and build new things with.

This repository is being set up. The packages, the docs and the full README land here step by step.

## Development

```bash
pnpm install
pnpm build
pnpm typecheck
pnpm lint
pnpm test
```

Node 24, pnpm 12, Nx, Vite 8, tsgo, oxlint and oxfmt.
